# chatWeb – Full-Stack Chat Application

A real-time full-stack chat web application built with **C#, ASP.NET Core, SignalR, Entity Framework Core, and SQL Server**, supporting user authentication and private conversations.

##  Features

* **Real-Time Communication:** Instant messaging powered by **SignalR** hubs for live chat updates without page reloads.
* **User Authentication:** Secure user registration and login workflows.
* **User Search & Connections:** Search for users by username and send/manage connection requests.
* **Private Conversations:** One-to-one messaging mapped securely through relational database structures.
* **Data Persistence:** Relational database management using **Entity Framework Core** and SQL Server.

##  Tech Stack

* **Backend:** C#, ASP.NET Core, ASP.NET Core SignalR, Entity Framework Core
* **Database:** SQL Server
* **Frontend:** JavaScript, HTML, CSS
* **Tools:** Git, Visual Studio Code

##  Database Architecture
Designed with Entity Framework Core, including robust relational models and composite keys for:
* Users
* Chats
* Messages 
* Chat Participants
